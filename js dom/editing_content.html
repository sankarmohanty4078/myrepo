Three Ways of Altering Page Content

1. Primary Approach (Easy but Less Efficient)

    Method Used: innerHTML

    ✔ Easy to write.
    ✔ Good for beginners.

    ❌ Browser parses the HTML string every time.
    ❌ Slower for repeated updates.
    ❌ Can introduce XSS (security) issues if user input is inserted.

    2. Better Approach

    Method Used: innerText

    ✔ Works only with text.
    ✔ Easier than creating text nodes.

    ❌ Still replaces existing content.
    ❌ Reads computed CSS before returning text, making it slower than textContent.

    3. Best Approach (Recommended)

      Method Used: createTextNode() + appendChild()

      ✔ Fastest.
      ✔ Creates actual DOM nodes.
      ✔ No HTML parsing.
      ✔ Safe from HTML injection.
      ✔ Preferred for dynamic DOM creation.
